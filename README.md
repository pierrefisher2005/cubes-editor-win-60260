## About Cubes Editor

Cubes Editor is a lightweight browser-based 3D editor centered on cube arrays. Its Minecraft-like environment provides a familiar visual format for creating, inspecting, and adjusting arrangements made from individual cube elements.

The tool is intended for users who want a straightforward way to work with block-based 3D layouts without relying on a complex editor workflow. Because it runs on the web, it can be accessed through a compatible browser from the published project page.
